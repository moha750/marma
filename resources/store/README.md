# أصول المتجرين — النسخ النهائية

**هذه هي المصدر. لا `store-assets/`.**

الملفات هنا أُنجزت يدوياً (فوتوشوب) انطلاقاً ممّا يولّده
`scripts/generate-store-assets.mjs`، ثم حُسّنت ألوانها وتخطيطها. فالسكربت
نقطة بداية لا مصدر حقيقة، ومخرجاته في `store-assets/` مؤقّتة ومستثناة من git.

| الملف | المقاس | أين يُرفَع |
|---|---|---|
| `play-icon-512.png` | 512×512 | Play Console ← بطاقة المتجر ← أيقونة التطبيق |
| `play-feature-1024.png` | 1024×500 | Play Console ← بطاقة المتجر ← صورة الغلاف |
| `appstore-icon-1024.png` | 1024×1024 | App Store Connect ← معلومات التطبيق |

## شروط لا تُخالَف
- **بلا قناة شفافية** — أبل ترفض الأيقونة الشفّافة، وقوقل تُظهرها بخلفية سوداء
- **بلا حواف مدوّرة مخبوزة** — النظامان يطبّقان قناعهما، والتدوير المُسبق يظهر مزدوجاً
- المقاسات أعلاه دقيقة ولا تقبل انحرافاً

## عند تعديل الشعار
شغّل السكربت لتوليد أساس جديد، أعد عليه لمستك، ثم **انسخ النهائي إلى هنا**.
